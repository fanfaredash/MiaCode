## 一、地雷音符(Mine) — 默认开启,无需任何开关

**测试谱**:`samples\mine_demo\maidata.txt`

**打开方式**:启动 `build\Release\MiaCode.exe`,File → Open 选上面的 `maidata.txt`(或其所在文件夹),进难度 `5`。

谱面内容(120 BPM,已扩展 = 66 物件 / 43 地雷,覆盖全类型 + 复合组合;前半多为「普通 / 地雷」成对便于对比):

- **基础对比**:`1`/`1m`、`2b`/`2bm`(break 雷)、`3x`/`3xm`(EX 雷)、`4bxm`(break+EX+雷)。
- **hold**:`1h[4:1]`/`1hm[4:1]`(空心胶囊)。
- **touch 全区**:A/B/C/D/E 区普通 vs 雷(`A1m`/`B1m`/`Cm`/`D1m`/`E1m`)。
- **touch-hold**:`A2hm[2:1]`/`Chm[2:1]`/`B5hm[2:1]`(空心扇)。
- **slide 多形状 + 雷**:`-`/`^`/`<`/`>`/`v(同 lane)`/`pp`/`qq`/`w(wifi)`,头星=空心星、轨道=灰色箭头;并验证 `m` 两种位置 `1-5[2:1]m` 与 `1-5m[2:1]` 都合法。
- **同押(each)含雷**:`1m/5`(雷+普通)、`1m/5m`(双雷)、`1m/3m/5m/7m`(四雷)、`1h[2:1]/5m`、`A1m/A5m`。⚠ **重点看 each 连线**:连线是否画到了地雷上(MajdataPlay 会把地雷排除出 each、不画连线——这是已知待修的保真缺口,见下)。
- **复合**:链式 slide `1-5[2:1]*5-3[2:1]m`、`2bm/6xm`、地雷在 `<HS*2>`/`<HS*0.5>`/`<HS*4>` 下。

**核心看点**:地雷以**空心/银色**贴图显示(区别于实心普通音符);**专用 mine 接近引导环**(不再是普通的粉色引导环);**不发声**;无理面板不报地雷;物量含地雷。

**验收清单**:
- [ ] 谱面能正常打开,**不报解析错**(这是移植第一动机)。
- [ ] 预览区:每个地雷以**空心/银色**贴图显示,明显区别于实心普通音符。
- [ ] 底部时间轴:地雷图标也是 mine 样式(非普通图标)。
- [ ] 播放:地雷**完全不发声**(无 answer/judge/break/ex/touch 音);普通音符正常发声。
- [ ] 「无理」面板:不为地雷生成任何判定/手型/重叠问题。
- [ ] 物量统计:**包含**地雷(产品决策 = 计入物量)。
- [ ] 视频导出:导出画面与预览一致(地雷可见、不发声)。

> 美术:skinSTD 已入库 mine 贴图;**skinDX 暂未做**(用 skinDX 皮肤时地雷会回退成普通贴图——这是预期,待后续由普通贴图色彩派生)。

## 二、负 HS 倒流(Negative HS) — **默认开启**

**测试谱**:`samples\negative_hs_demo\maidata.txt`

**打开方式**:负 HS 现已**默认开启**,直接启动 `build\Release\MiaCode.exe`,File → Open 上面的 `maidata.txt`,进难度 `5`。要**关闭**负 HS(恢复严格拒负)则设 `MIACODE_PREVIEW_REJECT_NEGATIVE_HS=1`。

谱面内容(120 BPM,已扩展 = 54 物件,HS 取值 [-4,-3,-2,-1.5,-1,0.5,1,2]):
1. 正向基准 `1,2,3,4`,然后 `<HS*-1>` / `<HS*-2>` / `<HS*-4>` 逐档倒流(负越大越快),再 `<HS*1>` 复位。
2. `<HS*2>` / `<HS*0.5>` 正向快/慢对照。
3. **逐类型**(均在 `<HS*-2>` 下):tap、break(`1b`)、ex(`2x`)倒流;slide(`1-5`)、wifi(`1w5`)、touch(`A1`)、touch-hold(`B1h`)、hold(`1h`)**不**倒流。
4. **同押混合**:`<HS*-2>1/1h[2:1]`(tap 倒流 + hold 不倒流,同一拍同时看对比)、`<HS*-2>2/2-6[2:1]`、`<HS*-1.5>1-5[2:1]/A1`。
5. **负 HS + 地雷**:`<HS*-2>1m`、`<HS*-2>1-5[2:1]m`、`<HS*-2>1hm[2:1]`、`<HS*-3>1bm,3xm`(地雷既倒流又是地雷)。
6. 每个负段都用 `<HS*1>` / `E` 复位收尾。

**验收清单**:
- [ ] `<HS*-2>` / `<HS*-1>` 段:tap / star / 连线**倒流** —— 从判定环**外侧飞入、命中在判定环**(与正向同样命中在环,只是方向相反:正向中心→环,倒流环外→环)。语义正确即可。
- [ ] 第 5 段:同为负 HS,**tap 倒流**,但 **hold / slide / touch 不倒流**(取绝对值,已用 MajdataPlay `NoteLoader.cs` 源码逐类型核实)。
- [ ] `<HS*1>` 段恢复正常正向流动。
- [ ] 判定时刻不变(倒流只改外观,不改音符到达判定的时间)。
- [ ] 注:**不做任何裁剪**(按你的决定)。倒流音符出生在环外、越过画布的那段飞行不可见(预览自然边界处理),代码只保证轨迹/命中语义正确——这是预期行为,不是 bug。
- [ ] 预览 vs 视频导出逐帧一致。
- [ ] **opt-out 验证(可选)**:设 `MIACODE_PREVIEW_REJECT_NEGATIVE_HS=1` 再开此谱 → `<HS*-2>` 应**报解析错**,证明逃生口有效。
