# MiaCode 菜单选中指示符设计规范

## 适用范围

所有用 `QAction` 表达“当前选择”或“可开关状态”的菜单项，包括内置菜单、
拓展贡献菜单和上下文菜单。预览菜单中的“预览模式”是视觉基准。

## 视觉规范

- 使用 `UiTheme::menuSelectionCheckIcon(checked)`，不得各自绘制另一套对勾。
- 图标画布固定为 `14 x 14` 逻辑像素。
- 对勾颜色使用当前主题的 `UiTheme::colors().accent`。
- 笔画宽度为 `1.8`，端点和转角均为圆角，并开启抗锯齿。
- 选中时显示单个 `√`；未选中时使用同尺寸透明图标。
- 透明占位必须保留，确保状态切换时文字起始位置和菜单宽度不跳动。
- 浅色、深色主题必须走同一个语义色接口，不得写死 RGB/十六进制颜色。

## 行为规范

- `QAction::setCheckable(true)` 与 `QAction::setChecked(...)` 负责语义和键盘/辅助功能状态。
- 每次 checked 状态变化后，同步调用 `setIcon(UiTheme::menuSelectionCheckIcon(checked))`。
- 主题变化后必须重新生成图标，以使用新的主题强调色。
- 单选组继续使用 `QActionGroup::setExclusive(true)`；视觉指示符不替代互斥语义。
- 拓展只能修改自身命令的 checked 状态，宿主负责套用规范图标。

## 禁止项

- 禁止依赖操作系统或 Qt Style 的默认 QAction 勾选图形；其形状、颜色和占位在不同平台不一致。
- 禁止使用 Unicode `√` 文本或 emoji 充当菜单图标。
- 禁止只在选中时设置非空图标、未选中时清空图标，这会造成菜单内容水平位移。
- 禁止拓展传入自定义对勾颜色或尺寸覆盖宿主设计。

## 验收

1. 内置“预览模式”和拓展开关的对勾形状、尺寸、颜色及左侧位置一致。
2. 连续切换开关时，菜单文字和菜单宽度不发生跳动。
3. 浅色和深色主题下对勾均清晰，主题切换后颜色随强调色更新。
4. 鼠标与键盘触发得到相同 checked 状态和视觉结果。
