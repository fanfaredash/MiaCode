# QML UI v2 功能缺口调研

> 状态：持续维护（2026-08-26）。本文件记录用户在 v2 中看得到、但尚未拥有等价 QML 实现的能力，
> 以免“接口存在”“Widget 后端存在”和“QML 已支持”三种状态混淆。

## 决策与边界

- 阶段 0b（扩展宿主）和 0c（被裁剪页面）已经延后；它们的既有 Widget 路径保留，不视为 v2 已缺失。
- 对**保留在 v2 界面、但没有可用 QML 实现**的入口，不隐藏也不置灰；点击后弹出“暂未更新支持”。
- 若既有后端操作可安全从 v2 调用，继续接入该操作，不以提示弹窗代替已存在的能力。
- `TimelineQuickModel` 正文增量更新与播放期高位内存平台为优化/取证项，均已延后，不作为本文件中的
  可交付功能。

## 已核查的能力

| 能力 | 现状 | v2 策略 | 后续归属 |
|---|---|---|---|
| 音频设置 | `MainWindow::onPreviewAudioSettings()` 仍是 Widget 对话框；工具栏没有 QML 页面或窄业务 API | 保留工具栏按钮，点击说明“暂未更新支持” | 阶段 3/设置域产品设计 |
| 预览设置 | `MainWindow::onPreviewVideoSettings()` 仍是 Widget 对话框；工具栏没有 QML 页面或窄业务 API | 保留工具栏按钮，点击说明“暂未更新支持” | 阶段 2 的 `PreviewSession` 后续工作 |
| 关于 MiaCode | `MainWindow::onAbout()` 仍是 Widget 对话框；帮助菜单未有 QML 对话框 | 保留菜单，点击说明“暂未更新支持” | 独立 QML 应用信息页 |
| 片头音文件与音量 | `QmlExportSession` / `ExportVideoPage.qml` 已提供选择、导入和 0%–200% 独立音量，并通过共享偏好、难度重播与 snapshot/worker 边界进入单/批量最终任务 | 已支持；保留原生桌面试听与成片回归 | 阶段 3 仅迁入 `ExportService` 作业模型，不再补功能 |
| 偏好设置 | 既有 `QmlCommandService::openPreferences()` 可调用 Widget 偏好页 | 保持可用，不弹“暂未支持” | 0c 延后期间保持现状 |
| 延迟检测、媒体处理/音轨工具 | `QmlEditorPageHost` 和工具侧栏已有调用既有后端的路径 | 保持可用，不弹“暂未支持” | 0c 延后期间保持现状 |
| Net 批量上传/下载、封面导出、ZIP 打包 | v2 已调用既有后端；缺的是原生桌面回归证据 | 保持可用并补回归，不标为功能缺失 | 阶段 3 `ExportService` |

## 本轮交付

- 工具栏“音频设置”“预览设置”及帮助菜单“关于 MiaCode”不再是无响应的禁用控件。
- 三个入口共享根窗口的 `MessageDialog`，以键盘或鼠标触发均可关闭，清楚说明功能尚未更新到 QML 界面。
- 视频导出“片头”页已补齐片头音文件选择/导入和独立音量，单/批量共用同一组 QML 控件与后端契约。

## 维护规则

1. 真正接入某能力时，将该行改为“已支持”，并删除对应的提示弹窗路由。
2. 不得为了让清单变短而删除用户可发现的功能入口。
3. 延后项目仅记录证据与前提；没有新的复现或明确排期不得继续扩张其实现范围。
