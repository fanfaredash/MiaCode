# Timeline 坐标与聚焦规格

本文档汇总当前确定的 Timeline 运行时坐标、状态切换、跨区联动规则，以及相关 UI 设计约束。

本文档目标：

- 作为 Timeline / 预览 / 编辑器联动实现的直接依据。
- 将 `L / R / C` 的职责、状态表和聚焦规则固定下来。
- 明确播放快照与当前文本分离后的行为边界。

## 1. 术语与基础定义

- `L`
  - 播放起始时刻。
  - 仅在“从暂停态点击播放”时更新。
  - `L` 只与时间有关，不吸附到具体物件。
- `R`
  - 预览运行时刻。
  - 播放时连续前进。
  - 暂停时可被用户直接修改。
  - `R` 只与时间有关，不吸附到具体物件。
- `C`
  - 编辑器光标对应的时刻。
  - `C` 只吸附到“逗号”锚点。
  - 若没有过去锚点，则 `C := 0`。
  - `C = 0` 时，文本落点视为 `L1 C1`。
- `播放快照`
  - 指进入播放时冻结的谱面内容。
  - 播放本体只使用播放快照。
- `当前文本`
  - 指编辑器中当前实时文本。
  - Timeline 渲染与 `C` 寻址只使用当前文本。

## 2. 锚点与寻址规则

- `C` 的锚点只认逗号 `,`。
- “最近过去锚点”指：时间不超过目标时刻的最近一个逗号。
- 若当前文本完全没有逗号，则 `C := 0`。
- 头部点击或 `Ctrl+点Timeline` 时，`C` 的定位规则为：
  - 先找“起始时间不超过点击时刻的最近过去行”。
  - 若有多行并列，取文档顺序靠前的那一行。
  - 取该行第一个逗号作为目标锚点。
  - 若该行无逗号，则退回全局最近过去逗号。
  - 若仍无逗号，则 `C := 0`。
- 点击文本、键盘移动文本光标、修改文本、`Ctrl+点文字` 时，`C` 的定位规则为：
  - 取当前位置对应的最近过去逗号。
  - 若无则 `C := 0`。

## 3. 播放快照与当前文本

- 每次从暂停态点击播放时：
  - `L := 当前R`
  - 重新创建播放快照
- 播放过程中：
  - 播放本体只按播放快照推进。
  - Timeline 始终按当前文本重绘。
  - `C` 始终按当前文本寻址。
- 因此，播放过程中允许修改文本，但：
  - 修改不会影响当前正在播放的内容。
  - 修改会影响 Timeline 绘制。
  - 修改会影响 `C` 的寻址结果。
- 若播放快照时长大于当前文本时长：
  - `R` 继续按播放快照推进。
  - Timeline 允许显示 `R` 落在当前文本末尾之后的空白区域。

## 4. 状态定义

- `播放中`
  - 播放本体正在按播放快照推进。
  - Timeline 永远聚焦 `R`。
- `暂停-R`
  - 预览暂停。
  - Timeline 聚焦 `R`。
- `暂停-C`
  - 预览暂停。
  - Timeline 聚焦 `C`。
- `停止位`
  - 不是独立状态。
  - `停止位 = 暂停-R 且 R = L`。

## 5. 状态表

| 当前状态 | 用户事件 | 下一状态 | `L / R / C` 如何变化 | Timeline 聚焦 | 备注 |
|---|---|---|---|---|---|
| `暂停-R / 暂停-C / 停止位` | 点击播放 | `播放中` | `L := 当前R`；`R` 从当前值连续前进；`Follow=开` 时 `C := <=R` 的最近过去逗号，否则 `C` 不变 | `R` | 同时创建新的播放快照 |
| `播放中` | 点击暂停 | `暂停-R` | `L` 不变；`R` 冻结在当前播放时刻；`C` 不变 | `R` | 播放停止推进 |
| `播放中` | 自然结尾 | `暂停-R` | `L` 不变；`R := 结尾时刻`；`C` 不变 | `R` | 自然结尾按暂停处理 |
| `任意` | 点击停止 | `停止位` | `L` 不变；`R := L`；`C` 不变 | `R` | UI 叫“停止”，内部仍属暂停态 |
| `暂停-*` | Timeline 纯 `R` 动作：按下开始拖动、滚轮平移 | `暂停-R` | 若动作开始时 `R` 不在画布中心，先 `R := 画布中心对应时刻`；之后再按用户动作继续改 `R`；`L / C` 不变 | `R` | 这里改的是真 `R`，不是仅改视图位置 |
| `播放中` | Timeline 纯 `R` 动作：按下开始拖动、滚轮平移 | `暂停-R` | 先暂停；若动作开始时 `R` 不在画布中心，先 `R := 画布中心对应时刻`；之后再按用户动作继续改 `R`；`L / C` 不变 | `R` | 等价于“修改 `R` + 暂停” |
| `暂停-*` | 拖动预览 slider | `暂停-R` | `R := slider 时刻`；`L / C` 不变 | `R` | slider 不走“先对齐画布中心”逻辑 |
| `播放中` | 拖动预览 slider | `暂停-R` | 先暂停，再 `R := slider 时刻`；`L / C` 不变 | `R` | 同样等价于“修改 `R` + 暂停” |
| `暂停-*` | 头部点击 | `暂停-R` | `R := 点击时刻`；`C` 按头部点击规则更新；`L` 不变 | `R` | `R -> C` 跨区动作；一律按点击时刻处理 |
| `播放中` | 头部点击 | `暂停-R` | 先暂停，再按上条处理 `R / C`；`L` 不变 | `R` | 会打断播放 |
| `暂停-*` | `Ctrl+点Timeline` | `暂停-R` | 与头部点击同规则：`R := 点击时刻`，`C` 再按头部点击规则更新；`L` 不变 | `R` | `Ctrl+点Timeline = R -> C` |
| `播放中` | `Ctrl+点Timeline` | `暂停-R` | 先暂停，再按上条处理 | `R` | 会打断播放 |
| `暂停-*` | 点击文本、键盘移动文本光标 | `暂停-C` | `C := 文本光标对应的最近过去逗号`；若无则 `0`；`L / R` 不变 | `C` | 纯 `C` 动作 |
| `播放中` + `Follow=关` | 点击文本、键盘移动文本光标 | `播放中` | `R` 继续按播放快照前进；`C := 文本光标对应的最近过去逗号`；`L` 不变 | `R` | 不打断播放，不抢聚焦 |
| `播放中` + `Follow=开` | 点击文本、键盘移动文本光标 | `播放中` | 用户可暂时改 `C`，但随后会再次被绑定到 `<=R` 的最近过去逗号；`L / R` 不变 | `R` | 覆盖时机无需单独细化 |
| `暂停-*` | 修改文本 | `暂停-C` | `L / R` 不变；Timeline 用当前文本重绘；`C` 按“当前文本 + 当前文本光标”重算 | `C` | 当前文本暂时不可解析时，按“最近已知逗号 / 0”兜底 |
| `播放中` + `Follow=关` | 修改文本 | `播放中` | 播放本体仍按冻结快照推进 `R`；Timeline 用当前文本重绘；`C` 按“当前文本 + 当前文本光标”重算；`L` 不变 | `R` | 文本改动不影响当前播放内容 |
| `播放中` + `Follow=开` | 修改文本 | `播放中` | 播放本体仍按冻结快照推进 `R`；Timeline 用当前文本重绘；`C` 按“当前文本 + 当前R”重新绑定到最近过去逗号；`L` 不变 | `R` | 若当前文本改短，`C` 可停留在最后一个逗号 |
| `暂停-*` | `Ctrl+点文字` | `暂停-C` | 先 `C := 点击位置对应的最近过去逗号`，再 `R := C`；`L` 不变 | `C` | `C -> R` 跨区动作 |
| `播放中` | `Ctrl+点文字` | `暂停-C` | 先暂停，再按上条处理 `C / R`；`L` 不变 | `C` | `Ctrl+点文字` 会触发暂停 |
| `播放中` | 打开 `Follow` | `播放中` | `L / R` 不变；`C` 立刻绑定到 `<=R` 的最近过去逗号 | `R` | 播放期间持续绑定 |
| `播放中` | 关闭 `Follow` | `播放中` | `L / R` 不变；`C` 保持当前值，此后不再自动跟 `R` | `R` | 只解除绑定 |
| `暂停-*` | 打开 / 关闭 `Follow` | 状态不变 | `L / R / C` 都不自动变化 | 原聚焦保持 | `Follow` 只影响播放中 |

## 6. 精简设计原则

- `L / R / C` 分工固定
  - `L` 只表示本次播放入口。
  - `R` 只表示运行时刻。
  - `C` 只表示编辑器光标相关的吸附时刻。
- `R` 与 `C` 默认独立
  - 暂停态下，`R` 和 `C` 默认互不影响。
  - 只有跨区动作才会显式同步另一边。
- 播放时 `R` 永远高于 `C`
  - 播放中时，Timeline 永远聚焦 `R`。
  - 播放中修改 `C` 不会抢聚焦。
  - 播放中任何直接改 `R` 的动作，都会先暂停。
- 跨区动作遵循“先改发起侧，再驱动另一侧”
  - `R -> C`
    - 头部点击
    - `Ctrl+点Timeline`
  - `C -> R`
    - `Ctrl+点文字`
- 播放快照与当前文本分离
  - 播放内容一旦开始，就以播放快照为准。
  - 当前文本变化只影响 Timeline 与 `C`，不回写当前播放内容。
- 时间边界固定
  - 不允许负时间。
  - `0` 为统一下界。

## 7. 相关 UI 设计总结

- Timeline 需要同时表达三个运行时坐标：
  - `R`
    - 用一条竖线表示。
    - 是播放中的主聚焦对象。
  - `C`
    - 用另一条独立竖线表示。
    - 与 `R` 颜色不同。
  - `L`
    - 在 Timeline 第一行、header 最下方顶部画一个三角形标记。
    - 与 `R` 使用同色系，但图形与线区分。
- `停止`
  - UI 保留“停止”按钮。
  - 点击后效果是将 `R` 拉回 `L`，并进入 `停止位`。
- `Follow`
  - UI 上继续保留“跟随预览”选项。
  - 语义限定为：仅在播放中将 `C` 绑定到 `R` 的最近过去逗号。
  - 暂停态切换 `Follow` 不应自动改动 `L / R / C`。
- Timeline 拖动
  - 用户从文本编辑切回 Timeline 拖动时，如果当前中心在 `C`，允许按下瞬间把 `R` 移到画布中心并重新聚焦 `R`。
  - 这一规则优先保证从用户视角看到的连续性。
- 点击 Timeline
  - 头部点击与 `Ctrl+点Timeline` 统一视为“按点击时刻处理”的 `R -> C` 动作。
  - 不对物件做额外吸附，`C` 的定位交给 `C` 侧规则。
- 点击文字
  - 普通点击文字只移动 `C`。
  - `Ctrl+点文字` 会执行 `C -> R`，并在播放中触发暂停。

## 8. 非阻塞参考项

以下内容不是当前规格阻塞项，但可以在后续实现中参考：

- Timeline 拖动起手可加入位移阈值，用于区分“单击”和“真实拖动”。
- 未来可考虑将运行时 `L / R` 的语义与导出区间 `[L, R]` 进一步对齐。

## 9. 当前结论

- 当前规格已经覆盖：
  - `L / R / C` 语义
  - 播放 / 暂停 / 停止位 切换
  - Timeline 与文本区的双向联动
  - `Follow` 行为
  - 播放快照与当前文本分离
  - 当前文本为空、无逗号、暂时不可解析时的兜底策略
- 当前剩余事项仅为实现细节与交互微调，不再属于阻塞性的规格缺口。
