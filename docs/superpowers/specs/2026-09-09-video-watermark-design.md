# 单视频“豆包AI生成”水印脚本设计

## 目标

提供一个独立的 Python 命令行脚本，为单个视频的右下角添加“豆包AI生成”文字水印。脚本不依赖 MiaCode 的源码、构建产物或运行时，只要求系统安装 FFmpeg。

## 方案

脚本通过 Python `subprocess` 调用 FFmpeg 的 `drawtext` 视频滤镜完成合成。相比 OpenCV/MoviePy，这种方式依赖更少、音频处理更稳定、长视频处理更适合直接交给 FFmpeg；相比纯 Shell/Bat，Python 更容易跨平台处理中文路径和参数校验。

## 命令行接口

```text
python add_watermark.py INPUT [--output OUTPUT]
                         [--font FONT] [--font-size PX]
                         [--opacity 0.0..1.0] [--margin PX]
```

- `INPUT`：必填，输入视频路径。
- `--output`：可选，输出路径；默认在输入文件名后追加 `_watermarked`，不覆盖输入文件。
- `--font`：可选，字体文件路径；默认按平台尝试常见中文字体。
- `--font-size`：可选，默认字号按视频宽度自适应或使用合理固定值。
- `--opacity`：可选，默认半透明。
- `--margin`：可选，默认右边和底边各 20px。

水印固定文本为 `豆包AI生成`，放置在右下角，使用白色半透明文字和轻微黑色描边，以提升在浅色画面上的可读性。

## 输出与错误处理

- 输出使用通用的 H.264 视频和 AAC 音频编码，保留输入视频的音频内容。
- 脚本启动时检查输入文件存在且可读，并检查 FFmpeg 是否可执行。
- 中文字体不可用、FFmpeg 失败或输出路径无权限时，打印明确的中文错误信息并返回非零退出码。
- 不自动删除或覆盖用户文件。

## 验证

使用 FFmpeg 生成一个短测试视频，运行默认命令和自定义输出命令，确认：

1. 生成文件存在且可以被 FFprobe 读取。
2. 输出视频时长和画面尺寸与输入一致。
3. 输出包含原音频流。
4. 水印位于右下角且文本为中文。
5. 缺少输入文件或 FFmpeg 时，命令以失败状态退出并给出可操作提示。
