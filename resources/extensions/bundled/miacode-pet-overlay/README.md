# MiaCode Pet Overlay

Adds a small draggable desktop pet window near the code area.

## Usage

1. Open MiaCode.
2. Open Preferences > Extensions.
3. Refresh extensions and enable `MiaCode Pet Overlay`.
4. The pet appears near the bottom-right of the preview.
5. Click the pet to play a one-turn spin animation.
6. Right-click the pet to change skins, set a hover skin, or close it.

Use Tools > Pet Overlay > Show Pet Window to launch it. Put skin images in `assets/skins`.
