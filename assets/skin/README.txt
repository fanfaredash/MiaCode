MiaCode Skin Import Guide

[简体中文]
放置位置：
- 将每个自定义皮肤作为一个独立文件夹放入 assets/skin。
- 文件夹名称会作为预览设置中的皮肤名称显示。

文件名与格式：
- 使用 PNG 图片文件。
- 文件名需要与内置皮肤资源保持一致，例如 tap.png、hold.png、star.png。
- 至少包含 tap.png、hold.png、star.png 这类核心文件后，皮肤才会出现在列表中。

注意事项：
- 不要删除或改名内置的 skinSTD、skinDX 文件夹。
- 建议复制内置皮肤文件夹作为模板，再替换需要修改的图片。
- 修改后若列表没有刷新，请重新打开预览设置。

[English]
Location:
- Put each custom skin in its own folder under assets/skin.
- The folder name is shown as the skin name in Preview Settings.

File names and formats:
- Use PNG image files.
- File names must match the built-in skin assets, for example tap.png, hold.png, star.png.
- The skin is listed only when core files such as tap.png, hold.png, and star.png exist.

Notes:
- Do not delete or rename the built-in skinSTD and skinDX folders.
- Copy a built-in skin folder as a template, then replace only the images you need.
- If the list does not refresh after editing files, reopen Preview Settings.

[日本語]
配置場所：
- カスタムスキンは assets/skin の下に、スキンごとに別フォルダーとして配置してください。
- フォルダー名がプレビュー設定のスキン名として表示されます。

ファイル名と形式：
- PNG 画像ファイルを使用してください。
- ファイル名は内蔵スキンと同じ名前にしてください。例：tap.png、hold.png、star.png。
- tap.png、hold.png、star.png などの主要ファイルがある場合にリストへ表示されます。

注意：
- 内蔵の skinSTD、skinDX フォルダーは削除または改名しないでください。
- 内蔵スキンのフォルダーをテンプレートとしてコピーし、必要な画像だけ差し替えることを推奨します。
- 編集後にリストへ反映されない場合は、プレビュー設定を開き直してください。
